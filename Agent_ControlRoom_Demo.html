    Build an agent like this with Claude (step by step)

    You don't need to code. You can turn Claude into a task agent using a clear "job description". Here's the recipe:

    1. Plan it on paper first (the recipe): write the GOAL, the TOOLS it can use (things it can ask you to look up or do), the LOOP (perceive -> plan -> act -> observe), and one GUARDRAIL (when it must ask a human).
    2. Open Claude and start a Project (or just a new chat). A Project lets you save the agent's instructions so you can reuse it.
    3. Give Claude its "job description" by pasting the prompt template below into the Project's custom instructions (or the first message). Fill in your goal, tools, and guardrail.
    4. Run the agent: tell it the goal. It will plan, then ask you for information (that's it "using a tool" - you play the tool and give it the answer, e.g. "the budget is $60").
    5. Let it loop: reply with results; it observes, adapts, and continues until the goal is met. When it hits the guardrail, it will pause and ask you to approve.
    6. Level up: ask Claude to "show the plan as a checklist", "track the budget", or even "make an HTML page that simulates this agent" - just like this one.

    Copy-paste prompt template (edit the parts in CAPS):

    You are a helpful "Party Planner Agent". Your GOAL: PLAN A SURPRISE BIRTHDAY PARTY UNDER $60. Work in a loop: 1) PERCEIVE - ask me for any info you need (one question at a time). 2) PLAN - list the next steps as a short checklist. 3) ACT - tell me which "tool" to run (e.g. "search venues", "check the budget") and wait for my answer. 4) OBSERVE - use my answer, update the plan, and track the budget. Repeat until the goal is met. RULES / GUARDRAIL: - Never go over the budget. If a choice would, stop and suggest a cheaper option. - Before spending money or messaging people, PAUSE and ask me (a human) to approve. - Keep it safe and kind (check for allergies, get an adult's OK when needed). Start by asking me your first question.
    Safety note for class: these are pretend agents - Claude asks a human before anything real. Follow your school's rules and get guardian permission before students use AI tools.

    Teacher talking points

    • Real agents juggle many steps: tools, a budget or goal, changing conditions, and re-planning - not just one answer.
    • Decisions show planning: when the agent asks you to choose, that's it weighing options - the heart of "planning".
    • Guardrails keep humans in charge: the red pauses are the most important part of a safe agent.
    • Same recipe every time: goal + tools + loop + guardrail. Students can design (and prompt) their own.
