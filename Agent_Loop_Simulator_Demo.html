    Watch for these moments: a yellow Observe that finds a problem, a blue Plan that adapts, and a red GUARDRAIL where the agent stops to ask a human. That mix - acting on its own but checking in - is what makes a good agent.

    How this maps to real AI agents (teacher notes)

    • Goal + loop: Real agents (self-driving cars, smart assistants, coding helpers) run this same Perceive-Plan-Act-Observe loop, often many times per second.
    • Tools: Notice the little tool tags (search, poll, maps). Agents act in the world by using tools, not just talking.
    • Adapting: When Observe finds a problem, the agent re-plans. That's why agents can handle messy, changing situations.
    • Guardrails: The red step is the most important - a safe agent pauses and asks a human before risky or uncertain actions.
    • Recipe: Every agent here = a goal + tools + the loop + a guardrail. That's the recipe students use to design their own.
