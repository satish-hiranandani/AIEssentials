📈 Regression = Predicts a NUMBER

The model looks at lots of past examples with known numbers, finds the pattern, then predicts a number for new inputs. There's no "right or wrong" — just closer or further from the real answer.

🏷️ Classification = Puts things into CATEGORIES

The model is trained on labelled examples ("this is spam", "this is not"). It learns the boundary between categories. For new inputs it gives a confidence score per category — the highest wins.

🔵 Clustering = Finds HIDDEN GROUPS

Nobody labels the groups — the algorithm discovers them by finding data points that are similar to each other. It's unsupervised: you don't tell it what the groups are, only how many (k) to find.

🎮
Gamer Type Clustering
30 gamers plotted by playtime vs skill — find the hidden groups
1

Each dot is a real gamer — plotted by how many hours they play vs their skill rating.

2

3

💡 Real world: Game studios like EA and Activision cluster their player base like this to decide which features to build next. "Casual" players want easier modes; "hardcore" players want ranked competitions.

💬 Discuss

  • With k=3, what name would you give each cluster? (e.g. "Casual Players", "Grinders"...)
  • Is it fair that game companies design features for the biggest cluster and ignore small groups?
  • Could being in the "casual" cluster mean you get shown more ads or easier (cheaper) content?
